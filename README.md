# 泰语字母记忆

一个简单易用的泰语辅音和元音记忆卡片应用，支持手机端访问，可部署在 GitHub Pages 上使用。

## 功能

- 📝 **辅音记忆**：完整收录泰语44个辅音（包含 ฃ、ฅ 等传统字母）
- 🔤 **元音记忆**：收录常用泰语元音符号和复合元音
- 📱 **移动端适配**：响应式设计，针对手机屏幕优化，支持触摸操作
- 🎲 **随机模式**：打乱顺序，提升记忆效果
- 🔄 **卡片翻转**：点击卡片或按空格键翻转查看读音、名称和类别
- ⌨️ **键盘支持**：支持方向键、空格键、N/P 快捷操作
- 👆 **滑动支持**：手机端支持左右滑动切换卡片
- 🎨 **简洁界面**：清爽的 UI 设计，操作简单直观

## 在线使用

部署到 GitHub Pages 后，可通过以下链接访问：

```
https://<your-username>.github.io/<repository-name>/
```

## 本地使用

直接用浏览器打开 `index.html` 文件即可使用，无需安装任何依赖。

## 快捷键

| 按键 | 功能 |
|---|---|
| 空格 / Enter | 翻转卡片 |
| → / N | 下一个 |
| ← / P | 上一个 |
| Esc | 关闭设置 |

## 部署到 GitHub Pages

1. Fork 或克隆此仓库到你的 GitHub 账号
2. 在仓库 Settings → Pages 中，将 Source 设置为 "Deploy from a branch"
3. 选择 Branch 为 `main`，文件夹为 `/ (root)`，点击 Save
4. 等待部署完成后即可通过 GitHub Pages 链接访问

## 数据说明

- 辅音按字母顺序排列，包含中文说明（高/中/低辅音类别）
- 元音包含发音符号及罗马音标注
- 发音标注参考通用泰语发音体系

## 技术栈

- HTML5、CSS3、JavaScript（原生，无框架依赖）
- 响应式设计，支持 PWA 思路
- 纯静态，零构建依赖
